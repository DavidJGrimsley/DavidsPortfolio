# Game design

[Human page](/portfolio/game-design) · [Portfolio](/portfolio)

Game projects and interactive prototypes focused on clear mechanics and player experience. The human page has individual projects and a playable demo.

- [Quasicombo](/portfolio/game-design/quasicombo): the homepage feature, an Unreal beat-’em-up with Quantum API braid evaluation, boss evolution, and adaptive music. Submitted to Global Quantum Game Jam 2026 and Moth Hack.
- [Neo Rock ’Em Sock ’Em Robots](/portfolio/game-design/neo-rock-em-sock-em-robots): tabletop AR robot boxing with multiplayer; second place at Ctrl+Space. Currently part of XR Showcase.
- [Guess the Qubit — Unreal](/portfolio/game-design/guess-the-qubit-unreal): the original desktop learning prototype, with a public Windows demo and a separate AR adaptation.
- [Football Game](/portfolio/game-design/football-game): a separate ReactVision Studio scene, awarded Best No-Code (Studio) at Ctrl+Space. It is not bundled into XR Showcase.

Quasicombo and both versions of Guess the Qubit connect to the existing [Quantum API](/public-facing/api/quantum).

For related software work, see [software development](/portfolio/software-development).
