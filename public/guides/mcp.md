# MCP servers

[Human page](/public-facing/mcp) · [Public tools](/public-facing)

The MCP index describes available Model Context Protocol servers. Use each server's page and linked repository for current setup and tool details.

- [App development MCP](/public-facing/mcp/mrdj-app-mcp): React Native, Expo Router, and full-stack development guidance.
- [Pokémon MCP](/public-facing/mcp/mrdj-pokemon-mcp): strategy resources and Pokémon data tools.

These servers are distinct from the Quantum API.
